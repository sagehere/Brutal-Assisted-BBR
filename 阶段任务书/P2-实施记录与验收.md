## 2. 已落地内容

### 2.1 可执行冻结规则参考模型

`tools/p2/replay/babr_model.py` 将阶段 01 的冻结规则变为可执行参考模型。该模型：

- 读取 `P1-冻结参数与用例.json`，拒绝非 `p1-baseline-v3`。
- 明确区分 `off / observe / lite`。
- Observe 仅计算 shadow candidate，不改变最终 pacing/CWND。
- W 只由 BBR packet-timed round 推进；ACK 事件本身不推进 W。
- 直接按白名单处理 `ProbeBW.Refill / Up / Cruise`，保护 Startup、Drain、ProbeRTT、ProbeBW.Down。
- 实现 Target、MaxRate、样本有效性、Soft/Hard queue-delay 的第一版确定性判定。
- 任何模式切换都会清理 shadow W，防止 Observe 状态泄漏到 Off/Lite。

该模型不是网络实现、不是性能证据，也不能替代真实宿主集成。

### 2.2 首批自动回归

`tools/p2/replay/test_babr_model.py` 当前覆盖：

### 2.3 冻结宿主 Observe 信号与 GuardEvent

已通过可重复 patch 在固定 quiche SHA 上接入只读 Observe 信号：

- `0001-babr-observe-signals.patch`：显式 BBRv2 phase、`end_of_round_trip`、baseline pacing/CWND、model delivery、sample validity/min RTT/max bandwidth、app-limited/loss 元数据。
- `0002-babr-transport-guard-accounting.patch`：记录真实 `LossDetected`、真实 PTO 分支的 `PtoFired`、`AppLimited`，并为 `PathChanged(path_id)`、ReceiverLimited、PolicyLimited 提供显式上层事件入口。
- Guard 使用单调计数而不是单个 last-event 槽，避免 Observe 快照之间覆盖安全事件。
- recovery 层不会从 RTT 变化推断路径迁移；PathChanged 必须由上层真实 path identity 注入。
- 未使用 `BBRv2::is_in_recovery()` 作为 BABR 安全信号。

Observe 计量字段当前严格区分：

- `model_delivery_rate_bytes_per_second`：BBRv2 模型交付率。
- `recovery_packet_bytes_sent`：recovery 层 packet bytes；**不是** socket-success。
- `transport_acked_bytes`：新确认的 transport packet bytes；**不是** unique-payload goodput。
- `transport_lost_bytes`：由真实 loss 事件累计。
- `unique_payload_delivered_bytes = None`：dedup/unique payload 桥未完成前保持 unavailable。
- `actual_socket_sent_bytes = None`：tokio-quiche socket/GSO success 桥未完成前保持 unavailable。

最新宿主验证：P2 Observe Gate run `35420993462` 成功；补丁顺序应用、patched quiche Rust 测试、只读边界检查全部通过。
