# 阶段 01：规格收敛与基线冻结任务书

版本：1.2；日期：2026-09-19；状态：**已完成，G1 Go**；预计投入：3–5 人日。  
依据：[评估报告 R2](../BABR规格审核与实施评估报告.md) §3–4；共同约定见 [阶段总览](00-阶段总览与执行约定.md)。

## 1. 目标与准入

目标是产出一份可直接指导阶段 02 的修订规格，解决全部 P0 和必要的 P1 定义。现有材料只有设计与评审文档，协议、宿主、基线提交、实现语言和实验环境均未锁定；这些是本阶段交付项，不能由后续开发者自行猜测。

准入材料：v0.2 原规格、R2 评估报告、目标应用需求和可用宿主清单。若业务需求暂不明确，按“单发送方向、持续有数据、受控长连接试验”建立明确标记的实验范围，不作生产适用性承诺。

## 3. 必须在本阶段作出的设计决定

### 3.1 宿主与集成

记录基线算法版本和实现提交，不以“BBR-style”替代。阶段白名单必须使用该实现的真实状态，禁止只用 `pacing_gain < 1` 作为所有保护状态的替代。Startup、Drain、ProbeRTT、恢复和其他主动降速阶段不得辅助。

明确最终输出裁剪的位置、实际发包事件如何反馈给 BBR，以及关闭辅助后窗口和 pacing 如何原子切回基线。若宿主无法满足上述要求，阶段结论只能是更换宿主或仅进入观测原型，不能放行实际辅助发包。

### 3.2 参数与预算

为以下项目给出确定值或确定公式，注明实验性依据；不可保留“适当”“稳定后”“若干 RTT”等空泛描述：

- Target 上限、允许范围与单位转换；进入/退出比例和持续规则。
- 唯一 W 更新算法、更新周期、每轮增幅和硬停止动作。
- 参考速率的取值、冻结时点、辅助增量上限和本轮发送预算。
- 截止时间、发送批次大小、不可撤销卸载队列的最大超调量和时间精度容差。
- 无收益观察期与改善阈值、样本有效性、最小激励和结果未知时的行为。
- Soft/Hard 条件、样本过期、失败次数、抑制时长、退避上限和路径重新学习规则。

首版可把本轮总发送字节作为保守预算；必须在提交发送批次前校验额度，超过时关闭辅助并返回基线，而非停止整个传输。预算失效或计时器调度迟到不能成为下一次继续辅助发送的理由。参数用于限定辅助增量，不得把整个基线速率永久钉在旧参考值上。

### 3.3 配置与测量

内部速率统一 byte/s、窗口字节、时间使用明确单位及单调时钟。Target=0/缺省关闭辅助；负数、非数、超范围与溢出有确定处理。唯一载荷经重传首次交付计一次，重复确认不再计数。区分发送端估计的唯一确认载荷与接收应用实测吞吐。

η 未知时标记无效，不赋值 1；Lite 不要求为损失补偿实现完整 A 估计器。已有 A 可观测则记录，无可靠 A 则标记不可用。探测阶段产生的有效带宽样本不被一概排除。

## 4. 设计验证与验收

每个用例必须给出输入、事件序列、预期状态、输出及预算变化；复杂分支用最小可运行规则检查验证，不能只重复原则。

| 用例 | 必须成立的结果 |
| --- | --- |
| C=150M、T=200M，RTT 几乎不增长 | 无须 RTT Hard 触发，仍在辅助预算内停止并进入抑制 |
| P_bbr=20M、T=1000M | 不能按旧公式直接跳至 265M；输出服从新辅助增长预算 |
| W=0，基线窗口已因恢复收缩 | 最终窗口精确遵循基线，且遵循相同外部策略 |
| 进入 Drain/ProbeRTT/恢复 | 同一决策中撤销辅助，由基线控制降速与 inflight |
| 停止 ACK | 时间到期后辅助失效，下一次发送不得用过期辅助额度 |
| Target 反复变更、短暂空闲 | 不清除同一路径的预算债务和退避 |
| η 分母太小或反馈未到齐 | 标记无效，不作为高效证据，不取消预算 |

## 5. 交付物与 G1 出口

交付：修订规格、宿主/接口记录、参数与计量字典、反例验证结果、恢复与 I/O 事件桥接设计、可复现 P1 自动门禁、阶段验收记录。原 v0.2 仅保留为设计背景，`P1-修订规格与冻结基线.md` 是唯一权威实现规范。

G1 通过条件：所有 P0 有确定规则与可复核反例结果；P1 计量、时钟、状态、路径和公平性测试要求已定义；无阻碍安全实现的未决项；宿主能支持这些规则。进入阶段 02 时同时交付已冻结的参数版本和用例编号。

不在本阶段实现完整控制器、性能调优、损失补偿或生产接入。若预计必须从零移植 BBR，应提交成本重估，不沿用原型工期。
