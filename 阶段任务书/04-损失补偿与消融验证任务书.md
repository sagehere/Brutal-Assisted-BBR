# 阶段 04：损失补偿与消融验证任务书

版本：1.0；日期：2026-09-18；状态：条件性阶段，未开始；预计投入：1–2 人周。  
依据：[评估报告 R2](../BABR规格审核与实施评估报告.md) §3、§5–6；前置：[阶段 03](03-对照实验与实施价值验证任务书.md) G3 明确建议继续；共同约定见 [阶段总览](00-阶段总览与执行约定.md)。

## 1. 目标与范围

验证 `T/A` 的损失补偿是否在相同安全约束下显著优于 BABR-Lite。必须保持 Lite 可独立运行，补偿可单独关闭；不能同时改变 CWND、W 算法、重传算法或基线版本来制造无法归因的收益。

准入还要求宿主能提供字节级确认/丢失及其修正信息。无法建立可靠 A 时，不启用补偿，直接交付“保留 Lite”的阶段结论。

## 3. 统计与集成契约

对同一发送批次中已判定结果的传输字节计算：

```text
A = acked_bytes / (acked_bytes + lost_bytes)
A_eff = max(A, A_min)
P_target_raw = min(T / A_eff, T × TargetCompensationCap)
```

上式只产生辅助候选，不构成最终发送许可。候选随后进入阶段 02 已验证的相对参考上限、单轮增幅、时间/字节预算、阶段白名单与宿主安全裁剪；TargetCompensationCap 不得被描述为相对网络基线的安全增益。

同一发送事件不能同时作为成功和丢失重复计入分母；迟到 ACK 和误判恢复按宿主规则修正或标记旧统计不可用，修正行为须可测试。尚未确认且未判丢的字节不计作失败；还需记录批次完成程度与过期，避免只看到早到 ACK 就把未成熟批次误判成高成功率。样本成熟规则与丢失检测阈值不另起一套互相冲突的机制。

重传是新的发送成本，唯一载荷交付另行去重；不能把传输字节成功比例直接当作应用 goodput 比例。A 的包长、协议开销及观测层次保持统一。若量纲不能直接匹配 T，应提供明确转换/校准并验证；否则仅保留损失遥测，不启用 `T/A`。

统计不足、分母为零、过期、结果不可靠时，本轮退回 Lite 候选并标记原因，不能把损失率当作零并宣称测量有效。A_min 与补偿上限的取值在消融前冻结，不照搬 v0.2 默认值作为已验证参数。

## 4. 专项验证

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| C01 | 不同包长、分批 ACK、暂未判定的数据 | A 按一致字节口径计算，待判定不混入分母 |
| C02 | 丢失后迟到 ACK、误判重传、重复确认 | A 修正可解释；唯一载荷不重复计数 |
| C03 | 0 样本、稀疏样本、A 接近 0、A 越界 | 不除零/溢出；无效样本退回 Lite，不绕过其他预算 |
| C04 | 1/5% 随机丢包及高 RTT、有剩余容量 | 检查完整版相对 Lite 的真实增量收益 |
| C05 | 低排队 policer、浅队列损失、连续突发丢包 | 不能因 A 下降而持续自我增益；按独立预算停止 |
| C06 | ACK 压缩/稀疏、路径变化、反向拥塞、应用受限 | 不把反馈异常当作可用容量证据 |
| C07 | 关闭补偿、W=0、基线保护阶段、运行中关闭辅助 | 相同事件下分别退回 Lite/基线，不留辅助窗口或预算残留 |
| C08 | 多流竞争、不同 Target/RTT/启动顺序 | 增量收益不能由竞争流持续退让换取 |

以上专项之外，阶段 02 安全检查全部保留；阶段 03 中与补偿相关的正常场景、不可达目标、动态容量、竞争及开销组必须重跑。更改计量接口影响全局统计时，应重跑受影响的全部指标分析。

## 5. 消融与验收

固定宿主、基线版本、pacer、CWND、W、探测时间/字节上限和主要评价场景。核心三组仅改变辅助关闭、Lite、Lite 加损失补偿这一因素。若必须调参，先在探索集完成，再用独立验证种子评估；不能将完整版本专属的更大预算算作补偿机制收益。

关键场景至少 10 次独立重复，统计方法沿用阶段 03。除完整版相对 BBR 的绝对结果，还必须报告相对 Lite 的差异、95% 置信区间、未达目标比例、流量成本、p95/p99 RTT、逐流公平性和计算开销。

完整版对 BBR 继续满足 R2/阶段 03 的收益、成本与安全门槛。对 Lite 的新增收益采用以下规划门槛，并在运行验证集前冻结：至少一个预先指定损失场景 goodput 提高 ≥5%，或恢复到 0.9T 的时间缩短 ≥10%，且收益区间排除零；无损场景退化不超过 3%。这是本任务书为增量复杂度设置的初始工程门槛，不是实测结论或标准。

对 Lite 的流量、延迟和竞争流退化也不得超过阶段 03 对应的 10%、`max(5ms, 10%×参照 p95 RTT)` 和 10% 初始边界；同时检查对 BBR 的完整边界，不能让各阶段容许退化叠加超标。独立运行安全失败一票否决，无效 η 或不可靠 A 不能因最终吞吐好看而豁免。

## 6. 交付物与 G4 出口

交付：字节比例估计与补偿最小实现、可关闭配置、计量与安全回归、三组消融数据/脚本、增量价值与限制说明、阶段验收记录。

- **保留完整版：**安全、绝对成本和相对 Lite 增量门槛全部通过；标明适用场景、已知失效场景和默认关闭策略。
- **退回 Lite：**无统计上可信或工程上有意义的增量，或者计量、成本、公平性无法达标；删除不需要的控制路径或保持隔离，不增加预测模型挽救结果。
- **停止并复核：**暴露基线集成或共享计量问题，回到对应阶段修正，暂停任何扩大试验。

本阶段不发布生产版本、不扩大公网试验，也不直接开启 Adaptive Target、Confidence Model 或内核实现。若候选达到四阶段门槛，后续生产化另行明确业务范围、部署运维和长期验证任务。
