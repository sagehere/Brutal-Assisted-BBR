# P1 冻结参数来源表

版本：`p1-baseline-v4`；日期：2026-09-20。

本表用于区分宿主事实、安全边界、实验初值、测量规则和验收门槛。除非另立规格版本，阶段 02 实现必须使用本表与 `P1-冻结参数与用例.json` 中的冻结值。

| 参数 | 值 | 类别 | 来源/理由 | 后续调整规则 |
| --- | ---: | --- | --- | --- |
| Target 最小非零值 | 1,000,000 byte/s | EXPERIMENTAL | 避免极小 Target 使效率分母与控制噪声主导 | 仅新规格版本 |
| Target 最大值 | 125,000,000 byte/s | EXPERIMENTAL | 首版实验范围上限 1 Gbit/s | 仅新规格版本 |
| 进入阈值 | D < 0.8T | EXPERIMENTAL | 仅 BASELINE→ASSIST 准入；给 Target 留出进入辅助的明显缺口 | P3 灵敏度分析后可修订 |
| 退出阈值 | D >= 0.9T | EXPERIMENTAL | 仅 ASSIST→BASELINE 退出；避免接近 Target 时继续加码 | P3 灵敏度分析后可修订 |

`0.8T <= D < 0.9T` 为冻结迟滞带：保持当前 BABR 状态，不把 0.8 进入阈值误当成 ASSIST 退出阈值，也不把 0.9 退出阈值误当成 BASELINE 准入阈值。
| 相对基线上限 | 1.10 x B_ref | SAFETY | R2 P0-2：限制 Target 不能直接授权大幅增速 | 不得在 P2 静默放宽 |
| W 单轮增量 | 0.05 / BBR round | EXPERIMENTAL | 首版保守探测步长 | P3 灵敏度分析后可修订 |
| Assist 最长时间 | 300 ms | SAFETY | R2 P0-1：不可达 Target 具有绝对退出 | 不得在 P2 静默放宽 |
| Assist 最多轮数 | 3 rounds | SAFETY | 与绝对时限共同防止长期辅助 | 不得在 P2 静默放宽 |
| 字节预算 | B_ref x min(3 x MinRTT, 300ms) | SAFETY | R2 P0-1/P0-2：总发送预算上界 | 不得在 P2 静默放宽 |
| Admission 粒度 | 单 QUIC datagram | SAFETY | 避免 GSO/批量发送在检查后越过预算 | 不得在 P2 改为大批次统一 admission |
| Deadline grace | 0 ms | SAFETY | timer 调度延迟不得延长新 Assist 许可 | 不得放宽 |
| Deadline 检查单位 | monotonic ms / 1ms resolution | HOST/MEASUREMENT | 与冻结规格统一时间单位；安全由发送入口硬判断保证 | 宿主变更时重审 |
| 不可撤销队列容差 | 2,400 byte | SAFETY | 首版限定已经进入不可撤销路径的最坏超调 | 仅新规格版本 |
| 无收益观察期 | 2 full rounds | EXPERIMENTAL | 给探测留出最小观察窗口 | P3 可评估 |
| 无收益阈值 | <1.02 x B_ref | EXPERIMENTAL | 小于 2% 模型增益视为没有可辨识收益 | P3 可评估 |
| Soft queue | max(10ms, 0.25 x MinRTT) | SAFETY/EXPERIMENTAL | 首版保守冻结阈值 | P3 可评估，不得绕过 Hard |
| Hard queue | max(20ms, 0.5 x MinRTT) | SAFETY | 明确停止条件，不是时延保证 | 不得在 P2 静默放宽 |
| Sample max age | 1 BBR round | MEASUREMENT | 控制输入必须接近当前网络模型 | 宿主采样语义变化时重审 |
| Efficiency 最小分母 | 1,000,000 byte/s | MEASUREMENT | 低分母时 eta 不稳定，标记无效 | P3 可评估 |
| Backoff 初值 | 30 s | SAFETY/EXPERIMENTAL | 连续失败后避免快速重试 | P3 可评估 |
| Backoff 上限 | 10 min | SAFETY/EXPERIMENTAL | 限制连续失败探测频率 | P3 可评估 |
| Ring entries | 4,096 / connection | MEASUREMENT | 遥测容量上限 | P2 开销验证后可收紧 |
| 日志序列化 | <=1 MiB/min | ACCEPTANCE | 控制观测开销 | P2 验证 |
| CPU p95 增量 | <=2% | ACCEPTANCE | P1 预设软件开销预算 | P2/G2 验证 |
| 内存 | <=256 KiB/connection | ACCEPTANCE | P1 预设软件开销预算 | P2/G2 验证 |
| 正常无损 goodput 回退 | <=3% | ACCEPTANCE | 阻止明显负优化 | P3 验证 |
| 发送成本增量 | <=10% | ACCEPTANCE | 限制用额外发送换吞吐 | P3 验证 |
| 竞争流退化 | <=10%（总 goodput 未改善时） | ACCEPTANCE | 公平性停止条件 | P3 验证 |
| 主要收益 | time-to-0.9T 改善 >=20% | ACCEPTANCE | 预注册主要场景指标 | P3 验证 |

类别定义：

- `HOST`：来自固定宿主能力或接口事实。
- `SAFETY`：为防止预算绕过、无限探测、恢复破坏等设定的硬边界。
- `EXPERIMENTAL`：首版试验冻结值，不是理论常数。
- `MEASUREMENT`：统计口径、有效性或遥测规则。
- `ACCEPTANCE`：后续阶段的 Go/No-Go 评价门槛。
